# Contributing to Repair Wiki

Thanks for wanting to contribute.

By contributing, you confirm you're the original author of your submission, have the rights to submit it, and agree it can be licensed under this project's license.

## Questions and chat

- Discord: https://discord.gg/7y9NP39k4C
- Or open an issue

## Reporting bugs

This tracker is only for the codebase and associated infrastructure. If you're using the wiki and something's not working, report it on [repair-wiki/wiki-issues](https://github.com/repair-wiki/wiki-issues/issues) instead.

Open an issue: https://github.com/repair-wiki/wiki/issues

Before reporting:
- Check for duplicates: look through existing issues before posting to avoid repeats

Include:
- System details: OS, browser, and platform (e.g. Windows, macOS, Linux, x86, ARM, Chrome, Edge, Safari, Firefox)
- Where it happened: repair.wiki, or self-hosted/local dev
- Inputs and outputs: what you did, what you expected to happen, and what actually happened
- Reproduction steps: clear, step-by-step instructions so we can replicate it
- Screenshots, console errors, or server logs, if relevant

**Security issues**: do not open a public issue. Email team@repair.wiki instead.

## Suggesting features

Open an issue describing the problem it solves and your proposed solution.

## Contributing code

1. Set up your dev environment (see README.md)
2. Look for issues tagged `good first issue` or `help wanted`
3. Open a PR

Commit messages: keep them simple, to the point, and legible.
